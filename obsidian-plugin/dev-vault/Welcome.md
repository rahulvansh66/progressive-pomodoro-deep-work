# Progressive Pomodoro dev vault

A throwaway vault for trying the plugin. `npm run build` (or `npm run dev`) installs it here.

1. Open this folder as a vault in Obsidian and allow community plugins when asked.
2. Click the timer icon in the ribbon, or run **Progressive Pomodoro: Open timer** from the command palette.
3. Pick [[Write report]] as the task, start a 2-minute block, and rate it when you finish.
4. Your sessions appear in `Pomodoro Log/<today>.md`, and in the backlinks of [[Write report]].

See [[Pomodoro queries]] for examples of querying the log with Dataview.
